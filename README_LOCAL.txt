GERADOR DE CRACHÁS — V15 LOCAL

Como usar:
1. Extraia esta pasta no computador.
2. Dê dois cliques em gerador_crachas.html.
3. Escolha a foto e informe o nome.
4. Clique em ✨ REMOVER FUNDO para usar a IA local do navegador.

IMPORTANTE:
- Não precisa de Node.js, npm, Render ou API Key.
- O processamento da foto acontece no navegador usando @imgly/background-removal.
- Na primeira remoção, o navegador precisa baixar o modelo de IA pela internet; depois ele fica em cache.
- A foto do funcionário não é enviada para um serviço de remoção de fundo; o navegador baixa apenas os arquivos do modelo.
- É necessário acesso à internet na primeira utilização para baixar a biblioteca/modelo.
- Se a política de segurança do computador bloquear módulos externos, o botão poderá apresentar erro. Nesse caso, use a alternativa de abrir o arquivo por um servidor local aprovado pelo TI.
